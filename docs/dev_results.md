## Before / after optimisation

| change | effect | where measured |
|---|---|---|
| rule files re-checked at most once a second (was every request) | about 1 ms less per request | median 3.5 ms -> 2.7 ms on a 110-snippet blind set |
| models and typosquat index loaded once at start-up | no first-request spike (first calls had taken 2-11 ms) | start-up measurement above |
| indexed package-name lookup (was a scan over every name) | 220 ms -> 0.2 ms per unknown package name | `docs/efficiency.md` |
| long input capped (first 150,000 + last 50,000 characters) | bounds worst case, padding cannot hide code | `tests/test_robustness.py` |
| models on vs off | accuracy on this sample is identical; the models matter for encoded blobs and prompt-injection wording | the two columns above |

Accuracy on code the engine had not seen is in `README.md` ("Results") and `docs/efficiency.md`.

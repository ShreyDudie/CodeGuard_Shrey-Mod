CodeGuard

Pre-execution safety check for LLM-generated code. Nothing is ever run; no LLM is called.

Drop a file here, or click to choose
.jsonl / .json / .txt / .pdf with {"code": "..."} objects (one after another is fine), .csv with a "code" column, or any code file

Does a blocked verdict really stop execution? This runs the project's fixed demo pair through the guard, in a temporary folder, and shows what happened. The safe snippet writes a marker file only if it runs; the unsafe snippet would write a different marker, so that file existing would prove it ran.

Only the harmless files demo/safe_snippet.py (runs) and demo/unsafe_snippet.py (scanned, never executed) are involved. Text you paste on the other tabs is never executed.
